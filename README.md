# Rita’s Spooky Fortune 🎃

Маленькая хэллоуинская веб-открытка: хрустальный шар с предсказаниями, мини-игра
«Trick or Treat» и финальная карточка «One more thing».

Статичный сайт: HTML + CSS + чистый JS, без сборки и бэкенда.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка, все SVG (шар, свечи, мыши, двери, конфета, тыква-ворчун, Дубай), meta и Open Graph |
| `styles.css` | Палитра, анимации, `prefers-reduced-motion` |
| `content.js` | **Все тексты**: имя, 20 предсказаний, реакции дверей, финальное письмо |
| `app.js` | Логика: колода без повторов, переворот карточки, двери, диалог |
| `assets/` | PNG с прозрачным фоном + `og.png` (превью ссылки 1200×630) |
| `pictures/` | Оригиналы картинок (сайт их не использует) |

## Как поменять тексты

Открой `content.js` — там комментарии на русском.

- Имя: `name`, `title`, `finale.greeting`.
- Предсказания: массив `fortunes`, у каждого `text` и `joke`. Можно добавлять сколько угодно.
- Финальное письмо: `finale.message` (каждая строка — абзац) и `finale.signature`.
- Апострофы внутри текста пиши как `’`, чтобы не ломать кавычки.

Заголовок во вкладке и превью в мессенджере берутся из `<title>` и `og:*` в `index.html`.
Если меняешь имя, поправь и их.

## Запуск локально

Достаточно открыть `index.html` в браузере. Или так:

```bash
python -m http.server 5520
```

## Офлайн

Всё работает без сети, кроме шрифтов Google Fonts (Creepster, Nunito). Без сети
подставятся системные шрифты.

## Картинки

Фон убран локальным скриптом (заливка от краёв и силуэты по яркости): Canva MCP был
недоступен из песочницы. Картинку с Ghostface (нож) не использовал: она не подходит
к уютному тону. Дубай, шар, двери, конфета и тыква-ворчун нарисованы в SVG.
